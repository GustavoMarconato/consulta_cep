# Consulta de CEP em Python

Projeto simples desenvolvido em Python com interface gráfica utilizando Tkinter para realizar consultas de CEPs brasileiros através da biblioteca `brazilcep`.

O principal objetivo desse projeto foi praticar conceitos importantes de programação, como:
- consumo de API
- manipulação de arquivos JSON
- criação de interfaces gráficas
- organização de código
- tratamento de erros

---

# Funcionalidades

Buscar informações de um CEP  
Exibir:
- Cidade
- Estado
- Bairro
- Rua

Histórico de CEPs pesquisados  
Limpar histórico  
Salvar histórico em arquivo `.json`



#Tecnologias utilizadas

- Python
- Tkinter
- JSON
- brazilcep
